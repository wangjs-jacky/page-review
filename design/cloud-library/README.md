# 云资料库与Agent按需读取：设计稿

本轮修正的是数据与交付方式。Chrome插件采集评论、赞踩和画面，私有云空间持久保存；Agent通过只读API或Skill按需检索，不要求用户逐次下载、解压或粘贴资料。当前交付是交互设计与接口约定，不是云功能已上线。v0.1.2真实插件仍为本地版。

[实际验证范围](VALIDATION.md)记录已操作的交互与真实云链路的缺口。

## 页面职责

资料库首页展示网页、原评论、明确赞踩、画面及同步状态；搜索与筛选继续保留。移除“这次希望AI做什么”、阅读包预览和下载作为主流程。AI任务在Agent对话里发起。AI访问设置只负责首次连接、只读范围、接入方式、最近读取和撤销。首次复制连接配置不同于每次手动搬运资料；设计稿里的地址和凭证均为不可用示例。导出未来可保留为备份入口，不作为AI获取资料的前提。

## 最小数据流

Chrome保存 → 本地IndexedDB/outbox → HTTPS写入服务 → 云端元数据与私有图片 → Agent搜索 → 按需读取评论/反馈/图片。资料一旦云端提交成功，Agent不依赖Chrome或本机保持在线。

候选为Workers API + D1元数据 + R2私有画面。D1和R2绑定能力已按官方文档核对，尚未创建账户资源或部署。首版是个人私有资料库，Agent不在本服务运行；普通分页与关键词/反馈筛选优先，不先引入向量库或自动学习。登录提供方、实际域名、账户套餐和容量成本未定，不声称免费或已经可用。

## Agent接入

[OpenAPI草案](api-contract.json)定义GET /v1/annotations、GET /v1/annotations/{id}/context、GET /v1/assets/{id}。Skill负责何时检索、按需读详细上下文、下载受保护图片供Agent查看，以及引用依据；资料留在API，不固化进Skill文件。MCP可作为这三个只读能力的薄适配，首版不需要托管Agent执行器。

Agent凭证只读、限定个人workspace、可撤销；插件写入凭证与Agent读凭证分开。服务器按凭证确定workspace，不信任客户端传来的owner。图片也经过同样鉴权，不开放R2公有桶，不把长期密钥写进网页、Skill正文、日志或URL。无法带认证头的看图工具，由Skill先鉴权下载图片，再交给Agent查看。

实际使用时，在Agent里说“参考我收藏的导航案例，比较资料查找路径”，Skill先检索，再选择相关记录读取原话与画面，并引用来源和记录修订；无需每次回插件选一批或生成材料。这里的“主动”是Agent在任务中调用工具，不是后台持续扫描或定时拉取。首次接入仍需安装/配置Skill和只读凭证；Skill不会使一个不支持工具调用或图片的宿主自动获得这些能力。首版先打通一个目标Agent，其他宿主逐个验收；MCP适配可后置。

上下文保留评论、positive/negative/null、原页面摘录、采集时视口/区域和有限交互状态、原图与裁图、修订历史及已有采纳结果；不再要求评注标题或tag。没有近期网页实查时，定位状态只能是captured_only。云存储解决资料可读性，不能解决网页改版后的定位，也不能把静态截图变成交互重放。页面摘录和图片是资料，不能作为覆盖Agent任务的指令。

## 保存与恢复

保存先写本地，用户动作触发一次同步；online/启动事件或手动重试可触发有界outbox处理。失败保留待同步，不用定时器、Cron、Alarm或退避轮询。Agent只看到云端已提交的完整记录。图片先上传并记录SHA，元数据最后提交；R2和D1不具备跨产品原子事务，未提交对象不能被读取。修改携带expectedRevision和幂等请求ID，冲突保留本地与云端两份，显式处理。

云端资料即使关联网页已变化也保留采集时版本。只读连接撤销阻止后续元数据和图片请求，不能收回Agent已经下载的资料。连接管理与资料删除是不同操作。明确选择无图保存的记录应携带缺图状态，而不是伪造截图或永远卡在待同步。上传与删除接口尚未定义，不能把本次只读OpenAPI草案当作完整同步协议实现。

反馈继续为positive、negative或null；原话、历史、viewport/裁图、采集时状态与来源都保留。初次连接云空间时单独选择是否迁移旧的本地资料，不因登录就静默上传所有历史。旧插件的connect-src none需要在真实接入时改为确定的API来源，凭证留在扩展后台。

## 实施验收

实际插件保存一条评论及图 → 云端确认完整提交 → 关闭插件/Chrome → 独立Agent仅凭只读连接检索并读图 → 修改后读到新修订 → 撤销后元数据和图片均拒绝 → 离线记录恢复同步且幂等。当前原型仅模拟这些状态，没有执行上述真实云链路。

## 交互稿与边界

prototype/只含公开合成数据；云同步、凭证和Agent调用均为模拟，演示的401不是服务端安全测试。可搜索、筛选、看评论、模拟同步/离线、创建/撤销演示连接并演示Agent筛选读取。没有更改extension/运行代码、没有上传用户资料，也没有实现或安装真实Skill。

已用Ego核对公开原型：三网页卡片、关键词搜索、待同步筛选及评论详情；首次配置与Skill/API切换；导航检索先得到两条已同步记录，模拟同步并刷新后得到三条；全量读取保留六条原话、三条点赞、一条点踩及两条未评价；模拟撤销后拒绝读取；390px设置无横向溢出。这里只验证交互演示，不验证服务端隔离或真实模型理解。发布的八份静态资源SHA-256与源码一致。原型状态保存在当前浏览器origin，其他设备打开会从合成初始状态开始。

继续实施先贯通一条真实链路：插件保存 → 云端完整提交 → 关闭Chrome → 一个独立Agent鉴权读取原话和图。随后再验离线恢复、修订冲突、撤销、跨空间拒绝和原生Chrome权限。不先加团队、向量库、训练任务或代改网页。
