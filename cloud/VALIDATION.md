# 0.2.0候选验证 · 2026-11-11

当前是已实现并在本机实际运行的候选，尚未部署Cloudflare或发布新版安装包。已发布0.1.2仍为本地版。

## 已验证

- 34项Node测试通过：插件行为与开关通知23项；Worker鉴权、只读范围、同空间隔离、附件提交、重复请求、过期修订、删除墓碑、中文分页及原话上下文8项；同步客户端离线、首次迁移选择及有界批次3项。Worker规则测试使用真实SQLite适配和内存R2，不能代替云端验证。
- 本机实际workerd+D1/R2：通过运行中的插件页面保存两网页评论，一赞一点踩，均保留真实浏览器视口和裁图，服务端提交后outbox清空。Chrome截图入口由适配器注入当前视口字节，裁图/编码/IndexedDB/HTTP均为实际代码。
- 实际断网：浏览器离线时本机保存修订3并保留队列；独立HTTP读取仍为服务端修订2。恢复在线事件后服务端变为修订3，队列清空且历史两条保留，没有定时重试。
- 本机服务关闭并重启，前端页面已卸载；独立Skill脚本仍读到两条评论、四个图片引用和原话历史，图片实际落盘并校验SHA-256。本会话Agent实际查看了读取的裁图。
- 模拟第二个拥有者写入造成真实409冲突后，页面对照本机与云端原话，用户动作另存本机为新记录；最终两网页三条记录均已提交，两个版本未覆盖丢失。
- 浏览器创建真实只读连接并下载首次配置。撤销后，独立HTTP对列表、上下文和图片均得到401；这不是静态稿的模拟分支。
- 390px访问设置范围和按钮可达，无横向溢出；桌面资料库保留搜索、回看及同步结果，不再显示下载阅读包主流程。
- npm run check、构建和空白检查通过。默认包15文件，无云地址时connect-src none；指定HTTPS源构建时只放行该源，不把密钥写进生成配置。Worker Wrangler dry-run通过。
