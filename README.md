# Page Review · 网页评注

在正常浏览的网页上，标下你关注的地方，保存评论和画面；下一次回来继续看，再把多个网页整理给 AI。

这是一个 **Chrome Manifest V3 扩展**。工具栏只有一个图标，功能从页面右下角的悬浮球展开。无需把网站导入一个独立编辑器。

## 云空间接入设计（未上线）

新方向是「Chrome采集 → 私有云资料库 → Agent通过只读API或Skill按需读取」，无需逐次下载或复制资料。见[交互设计与接口草案](design/cloud-library/README.md)。该目录是公开合成数据的静态原型，云同步、连接和Agent调用均为模拟；下面v0.1.2仍是本地版安装与使用说明。

## 安装

需要桌面 Chrome 120 或更高版本。

1. 从 [Releases](https://github.com/wangjs-jacky/page-review/releases) 下载 `page-review-0.1.2.zip`，解压到一个保留的文件夹。
2. 打开 `chrome://extensions`，开启右上角「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择包含 `manifest.json` 的解压目录。
4. 在 Chrome 扩展菜单里将 Page Review 固定到工具栏，打开普通网页，点击图标启用。

这是开发者模式安装包，没有上架 Chrome Web Store，也不是签名 CRX。更新时解压新包并在扩展管理页重新加载；尽量保留同一安装路径，以免 Chrome 分配不同的扩展身份和存储空间。

## 使用

- **启用或关闭：** 点击 Chrome 工具栏图标直接切换，开关作用于当前浏览器中的 Page Review。关闭会移除页面浮层，保存的评注不会删除。
- **悬浮球：** 默认在右下角，可拖动贴边。菜单的「收起到右下角」会合上面板并将小球归位。小球上的关闭按钮或菜单「关闭」可关闭工具，再点击扩展图标恢复。
- **评论：** 点选或框选后，直接在浮动输入条写评论，点击勾选图标保存。没有评注标题或分类标签。Ctrl / ⌘ + Enter保存，额外按Shift可保存并继续点选。
- **可选反馈：** 👍 / 👎 可以与评论一起保存，也可以单独保存；再次点击同一个图标取消选择。不选表示未评价，不会从原话或旧分类推断你的喜好。
- **画面：** 选择关注对象时记录当前视口，并保存关注区域裁图。悬浮工具本身会暂时隐藏。截图失败会明确显示，只有明确勾选「仍然保存」后才能无图保存。
- **复访：** 启用时会尝试重新定位旧标记。内容重复、目标移除或页面明显变化时停止贴回，仍可从本页评注或保存库查看原话与原画面，也可手动重新定位。
- **多页整理：** 小球 → 全部保存的网页，按网站/标题/评注搜索，选择网页或单条评注，再准备给 AI。
- **交给 AI：** 输入本次任务，下载 ZIP 阅读包。解压后包含 `README.md`、`manifest.json` 和对应图片，可放进 Agent 能读取的工作目录。也可以复制说明，再手动提供图片。当前没有绑定某个 Agent 或自动发送对话。

本页评注可编辑原话与反馈；保存库保留修改前的原话、反馈历史和记录时画面。需要时可补充「采纳 / 不采用」及理由，这些内容也会进入阅读包。

## 数据与权限

评注和图片存于扩展自己的 **IndexedDB**，开关和悬浮球位置存于 `chrome.storage.local`。跨网页共享一个本地保存库，不依赖网页自身的 localStorage。无账号、云端服务、分析统计、模型请求或自动上传。

明确反馈存为 `feedback: "positive" | "negative" | null`，随原话、画面和历史一起导出。旧记录默认保持未评价；保留的旧分类字段不等于点赞或点踩。这些是后续AI分析或训练可使用的原始材料，本版不执行自动偏好学习或模型训练。

扩展声明 `activeTab`、`scripting`、`storage` 和 `<all_urls>` 网页访问权限。网页权限用于跨网站注入工具、在复访时恢复标记，以及调用 Chrome 的视口截图接口；默认关闭，关闭时不会向新页面注入内容脚本。代码只注册 HTTP/HTTPS 顶层页面，没有文件访问、跨源 iframe 内部注入或浏览历史采集逻辑。

只有主动标注的内容及其画面会进入保存库。图片可能包含视口内其他内容，请在交给 AI 前检查阅读材料。卸载扩展、删除浏览器配置或清除扩展数据会失去本地记录；重要材料请及时导出。当前版本的阅读包用于保存与 AI 阅读，尚不提供重新导入或云同步。

## 当前边界

- `chrome://`、扩展管理页、Chrome Web Store、浏览器内置 PDF 和本地文件等受限页面不支持注入。跨源 iframe、封闭 Shadow DOM 及 Canvas 内部结构不提供精确对象定位，可在可操作的网页视口中框选其画面。
- 重新定位综合元素内容、稳定属性、上下文和页面相似度，是保守的启发式方法；不保证任意网站改版后的语义一致。区域尺寸或页面内容改变时，区域标记会更容易进入待确认状态。
- 整页意见附的是**记录时当前视口**，不是自动滚动拼接长截图。动态交互可以保存当时画面和有限的悬停/展开状态，不能代替录屏或重放整段交互。
- 已保存记录可跨页面和浏览器会话保留；未保存输入只保留在当前页面内存中，刷新前请保存。
- 未集成 MCP、Agent 会话发送、团队协作、偏好学习或自动改站。

## 本地开发

页面内评论使用紧凑输入条与反馈图标，保存库及材料区沿用已有布局。`extension/content.css`在构建时封装为内容脚本使用的样式，不需要运行时网络请求。

项目无第三方运行时或构建依赖，需要 Node.js 20+；完整 ZIP 测试另需系统 `unzip`。

```sh
npm run check
npm test
npm run build
```

将 `dist/page-review/` 作为已解压扩展加载。构建同时产生 `dist/page-review-0.1.2.zip`，只包含13个运行文件，不包含测试适配器、测试页面、机器配置或浏览器数据。

```text
extension/           MV3 清单、后台、页面悬浮层、保存库、导出规则
scripts/build.mjs    复制白名单、生成图标、打包可安装 ZIP
scripts/check.mjs    清单、语法及资源检查
scripts/fixtures.mjs 合成网页和浏览器集成验收环境
tests/               定位、权限边界、原话历史、并发保护、ZIP 等测试
```

## 验证说明

核心规则和后台消息处理使用 Node 测试。浏览器集成环境运行实际内容脚本、后台逻辑、真实 IndexedDB、截图裁剪和阅读包导出，**Chrome API 由测试适配器提供**；画面输入来自实际浏览器视口。该环境只用于开发，不进入安装包。

本次执行环境的 Ego 接口不开放原生扩展加载，因此不把适配验收描述为「原生 Chrome 安装、工具栏真实点击、权限与截图 API 已实测」。加载解压包后的这些原生路径仍需在桌面 Chrome 验证；发布源码和可加载安装包不等于 Chrome 商店验收。

0.1.2 已在 Ego 适配环境验证紧凑输入：正常单行约50px高，没有标题、分类或截图说明底栏；390px下输入与图标完整可达。评论加点赞、只点踩、仅评论均经实际UI保存；刷新后评论、画面及标记保留，编辑后的原话和反馈历史保留。两页三条阅读包实际下载解包，六张PNG/JPEG完整，JSON和Markdown均区分明确赞踩与未评价。

上述验证继续使用 Chrome API 适配器，不代表原生扩展加载、工具栏点击、权限或截图 API 已通过。
